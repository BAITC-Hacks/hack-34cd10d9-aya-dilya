# Firebird: сценарий демонстрации

Статус: UI интегрирован с настоящим сервисом A из коммита `b645207`. Подбор выполняется локально по каталогу. Примеры заполняют условия, а не подставляют ответы.

## Подготовка

```sh
npm ci
npm run check
npm run build
npm run dev -- --host 127.0.0.1
```

Открыть адрес Vite, обычно http://127.0.0.1:5173. Проверено на Node.js 24.19.0 и npm 10.8.2. Команды не требуют ключей внешней LLM.

## Основной показ

В блоке «Нужна отправная точка?» выбрать пример и нажать «Подобрать подрядчиков».

1. **Плотная категория:** Алматы, 04.10.2026, корпоратив, ведущий, 2 000 000 ₸. Ожидаются HK-29829, HK-35215, HK-27222. Показать `summary`, причины в карточках, начальные цены и снимок условий.
2. **Другая дата:** тот же запрос на 05.10.2026. Ожидаются HK-88430, HK-44733, HK-77838. Объяснить, что календарь повлиял на подбор.
3. **Редкая категория:** Алматы, 23.09.2026, свадьба, флорист, 350 000 ₸. Ожидаются два профиля HK-39372 и HK-90001. Здесь видны оценочная цена и синтетический профиль; третья карточка не выдумывается.
4. **Один результат:** выбрать пример «Декабрь: все кандидаты заняты», затем вручную поменять дату на 03.12.2026. Астана, флорист, корпоратив, 350 000 ₸ → один профиль HK-90002 («Хаку»).
5. **Категория отсутствует:** Астана, лайв-бэнд, корпоратив, 04.10.2026, 2 000 000 ₸. Отдельное сообщение об отсутствии категории и предложение изменить город/категорию.
6. **Нулевой бюджет:** пример «Категория есть, бюджет исключает всех». Показать `summary`, отсутствие карточек, предложения изменить условия. Бюджет остаётся нулевым, автоматического ослабления нет.
7. **Все заняты:** исходный декабрьский пример на 02.12.2026 возвращает пустой результат с причиной занятости.
8. **Необязательные поля:** пример площадки с русским языком и 8 часами возвращает HK-58236, HK-69010, HK-99701. Пример флориста с 24 часами возвращает те же два профиля редкой категории; смысл неприменимой длительности объясняет сервис.
9. **Предположенный город:** загрузить плотный пример, выбрать категорию «Фото и видеобудки», выполнить подбор. В карточке Аски Ленгли видны метки «Город предположен» и «Цена оценочная».

После выдачи изменить бюджет без отправки: снимок условий остаётся прежним, появляется «Условия изменены — повторите подбор». Нажать кнопку для обновления результата.

## Ошибки и асинхронность

- На обычной странице отправить пустую форму: ошибки обязательных полей, фокус на первом поле.
- В заполненном запросе поставить бюджет −1: ошибка под полем; нулевой бюджет при этом допустим.
- Для воспроизводимой проверки редких технических состояний открыть **тестовый стенд** `/tests/ui/browser.html`. Он явно помечен, использует настоящий сервис с искусственными задержками/ошибками и не входит в production build.
- Режим «Задержка первого ответа»: загрузить плотный пример, отправить, сразу изменить бюджет на 0 и снова отправить. Второй ответ приходит первым. Спустя 3 секунды выдача остаётся пустой и относится к бюджету 0.
- Повторить в режиме «Устаревшая ошибка»: поздняя ошибка первого запроса не скрывает новый результат.
- «Техническая ошибка»: заполнить пример и отправить; появляется сообщение с кнопкой повтора. Условия сохраняются.
- «Ошибка справочников»: форма заменена понятным сообщением и кнопкой повторной загрузки.

## Проверено в браузере 23.09.2026

Все восемь сохранённых сценариев A совпали по id и статусу; дополнительно проверены единичная выдача, ошибки формы, изменение календарной даты, снимок условий, три флага происхождения, загрузка, технические ошибки и гонки ответов. На 320/375/768 px нет горизонтальной прокрутки; мобильные карточки осмотрены. Автотесты: 21 ядра + 5 адаптера, build проходит.

Цены «от», отметки календаря и синтетические данные не выдавать за подтверждённые предложения реальных подрядчиков. Бронирования, оплаты, регистрации и отправки сообщений нет.

## Новые сценарии smart-matching

На обычной странице выбрать «Умный подбор: IT-корпоратив» и отправить. Ожидаемый порядок: HK-75012, HK-88430, HK-44923. У Джинбея показана цитата о технологических форумах; у остальных — отсутствие подтверждения темы. Удалить пожелание и повторить: первым станет HK-88430. Это тематическое совпадение, а не подтверждённый опыт работы с IT-компаниями.

Выбрать «План Б: бюджет выше всего на 4,2%». Основная выдача пуста, бюджет в форме и снимке — 480 000 ₸. Отдельное предложение повышает его до 500 000 ₸; карточек до применения нет. Нажать «Применить»: форма и снимок обновляются, появляется HK-88430. Для проверки даты выбрать «Декабрь: все кандидаты заняты»: предложены 03.12 и 01.12; дата меняется только по кнопке соответствующей альтернативы.

Без серверного ключа маркировка — «Объяснение по данным каталога». После успешной и проверенной генерации сервером появятся маркировка AI и раскрываемые факты. Реальный вызов OpenAI не проверен. Только для проверки отображения на изолированном `/tests/ui/browser.html` есть режим «Тест маркировки AI (без вызова модели)»; он не доказывает работу модели и не входит в сборку продукта.

Запуск production с API: `npm run build`, затем `npm run start` (127.0.0.1:4173). Не использовать `preview` для проверки серверного AI.
