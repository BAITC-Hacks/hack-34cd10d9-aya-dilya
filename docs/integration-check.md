# Проверка общей версии Firebird

Дата: 23.09.2026. Ветка проверки: `codex/integration-check`.

UI-коммит `e073446` уже включает часть A `b5a9bfb` через merge-коммит
`9fd8d10`. Повторное объединение частей не потребовалось. Общий контракт,
каталог, правила подбора и зависимости сохранены.

## Изменения при интеграции

`npm test` и, следовательно, `npm run check` теперь запускают одновременно
тесты ядра и UI-адаптера. Раньше пять тестов адаптера нужно было вызывать
отдельно. Команды в README и сценарии демо приведены к общему запуску.

## Автоматические проверки

- Чистая установка: `npm ci --offline` с предварительно заполненным кешем.
- `npm run check`: актуальность каталога, TypeScript, 26 тестов и сборка
  сервиса для браузера прошли. В тестах ядра проверяются 6 600 запросов
  по всему календарю и восемь сохранённых сценариев.
- `npm run build`: сборка полного приложения прошла. Получены HTML, CSS
  и JavaScript; тестовый стенд не включён в production entry point.
- `git diff --check`: замечаний нет.

Окружение: macOS, Node.js 20.20.0, npm 10.8.2.

## Проверка через интерфейс

В локальном приложении на 127.0.0.1:5173 проверены:

- Все восемь сохранённых запросов: фактические id и порядок карточек
  совпали с ожидаемыми. Отдельно показаны оба вида пустой выдачи.
- Отправка пустой формы и отрицательного бюджета: ошибки видны,
  некорректный запрос не превращается в пустую выдачу.
- Маркировка синтетического профиля и оценочной цены в редкой категории.
- Снимки ширины 320 и 375 px: ширина документа не превышает viewport.
- В стенде с задержкой первый запрос не перезаписывает более новый
  результат с бюджетом 0 после своего завершения.
- В стенде с технической ошибкой показано сообщение с повтором запроса;
  параметры формы сохранены.
- В основном приложении ошибок в консоли браузера не обнаружено.

## Статус

Общая версия готова к командному просмотру и демонстрации. Работа основана
на правилах и данных каталога; внешняя LLM не подключена. Сайт не опубликован,
main не изменён. Ветки участников сохранены; объединённая версия предлагается
через отдельный pull request.
