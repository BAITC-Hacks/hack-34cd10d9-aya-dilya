# Firebird

MVP команды Aya & Dilya: русскоязычный интерфейс подбирает до трёх event-подрядчиков по городу, дате, формату, категории и бюджету в тенге. Язык и длительность необязательны.

## Запуск

Нужны Node.js 20.19+ в ветке 20.x или Node.js 22.12+ и npm.

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Откройте адрес, напечатанный Vite (обычно http://127.0.0.1:5173). Проверки и сборка:

```sh
npm run check
npm run build
npm run preview -- --host 127.0.0.1
```

`npm run check` проверяет актуальность данных, TypeScript, все 26 тестов (21 ядра и 5 UI-адаптера) и браузерную сборку сервиса. `npm run build` собирает полное приложение.

## Что работает

- Форма получает справочники через `getCatalogOptions()`; даты ограничены календарём 23.09–31.12.2026.
- Адаптер `src/pages/recommendationServiceAdapter.ts` подключает настоящий `recommendationService` из `src/core/index.ts`. Подбор выполняется локально по 66 профилям, без внешней LLM и сетевого API.
- Карточки показывают имя, категорию, город, цену «от», готовое `explanation` сервиса и календарную доступность. Над результатом выводится `summary` без пересказа со стороны UI.
- `synthetic`, `cityImputed`, `priceImputed` показаны независимыми русскоязычными метками.
- Есть состояния загрузки, 1–3 результатов, отсутствующей категории, пустой выдачи, ошибок ввода и технических ошибок с повтором.
- Рядом с результатом сохраняется снимок отправленных условий. Редактирование формы не меняет старый результат; интерфейс предлагает повторить подбор. Устаревшие ответы и ошибки игнорируются.
- Примеры из `src/data/demo-queries.json` только заполняют форму. Нажатие кнопки вызывает настоящий сервис, заранее подготовленных ответов в продукте нет.
- Интерфейс адаптируется к мобильной ширине, поддерживает клавиатуру, подписи полей и объявления статуса.

Подбор по этому каталогу не означает проверку реального подрядчика. Синтетические профили и оценочные город/цена помечены. «По календарю не занят» означает отсутствие занятости в данных на выбранную дату; это не подтверждённая доступность. Начальная цена не является итоговой сметой. Параметры не ослабляются автоматически.

Бронирования, оплаты, регистрации и отправки сообщений нет. Сайт не опубликован.

## Интеграция A и B

Ветка B: `codex/recommendation-ui`. Часть A (`origin/codex/matching-core`, `b5a9bfb`) объединена с B; документация B сохранена. Общий контракт, `src/core`, `src/data`, `scripts`, тесты ядра, зависимости и конфигурация TypeScript не изменялись участником B.

Точка входа UI — `index.html` → `src/main.tsx` → `src/pages/RecommendationPage.tsx`. Дополнительные зависимости не нужны. Для подключения к другой ветке сначала убедитесь, что в ней есть коммит A `b5a9bfb`, затем перенесите отдельный UI-коммит B. Хеш UI-коммита указан в сообщении о сдаче. Если переносится только UI-коммит, `docs/ui-plan.md` должен существовать из документационного коммита `0846429`; альтернативно перенесите готовую ветку B после проверки её diff. Автоматического слияния в main не выполнялось.
