# Firebird

MVP команды Aya & Dilya: планируется подбор до трёх event-подрядчиков по условиям мероприятия с конкретными объяснениями.

## Текущий статус

В этой ветке подготовлена документация интерфейса. Приложение, общий контракт и сервис рекомендаций пока отсутствуют; форма и подбор ещё не работают.

- [План интерфейса](docs/ui-plan.md): поля, карточки, состояния, интеграция и проверки.
- [Сценарий демо](docs/demo-script.md): план проверки после интеграции.

Команды установки, запуска и проверки будут добавлены после получения каркаса от участника A и фактического запуска. Сейчас запустить приложение из этой ветки нельзя.

## Совместная работа

Участник A создаёт каркас, общий контракт и сервис. Участник B работает в отдельном worktree на ветке `codex/recommendation-ui` и отвечает за интерфейс. B не редактирует `src/core`, `src/data`, общий контракт и зависимости.

Для продолжения нужен коммит A с каркасом и `src/shared/contracts.ts`, а также точки входа `getCatalogOptions()` и асинхронного `recommend()`. После согласованного подключения интерфейс использует сервисный адаптер без собственных фильтров и ранжирования. Если сервис ещё не готов, тестовые ответы будут явно обозначены как демонстрационные.

Текущие изменения B — только документация. Их можно перенести отдельным коммитом, предварительно проверив README на конфликты. Автоматическое слияние веток и публикация сайта не выполняются.
